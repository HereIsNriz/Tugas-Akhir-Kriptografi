# Daftar Referensi

Referensi di bawah ini menjadi acuan teori pada seluruh dokumen di folder `docs/`.
Notasi `[n]` di dalam dokumen merujuk ke nomor pada daftar ini.

> Catatan: bila dosen memberikan diktat/slide resmi, tambahkan sebagai referensi
> utama (mis. `[0] Materi Kuliah Kriptografi, ...`) lalu sesuaikan penomoran.

1. W. Stallings, *Cryptography and Network Security: Principles and Practice*,
   Pearson.
2. B. Schneier, *Applied Cryptography: Protocols, Algorithms, and Source Code in C*,
   John Wiley & Sons.
3. NIST, *FIPS PUB 180-4: Secure Hash Standard (SHS)*, 2015.
4. K. Moriarty (ed.), *PKCS #1: RSA Cryptography Specifications Version 2.2*,
   RFC 8017, IETF, 2016.
5. B. Kaliski, *PKCS #5: Password-Based Cryptography Specification Version 2.0*,
   RFC 2898, IETF, 2000.
6. G. Bradski, "The OpenCV Library," *Dr. Dobb's Journal of Software Tools*, 2000;
   dokumentasi OpenCV untuk Haar Cascade dan LBPH (`cv2.face`).
7. S. Nakamoto, "Bitcoin: A Peer-to-Peer Electronic Cash System," 2008.
8. NIST, *SP 800-132: Recommendation for Password-Based Key Derivation*, 2010.
